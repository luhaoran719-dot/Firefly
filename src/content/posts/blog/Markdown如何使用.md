# Markdown的基本语法和注意事项
## 标题
### 这是一个标题
1. 在文字前打“#”即可，markdown支持六级标题,同时![[Pasted image 20260531100909.png]]可以收缩标题下面内容。
**注意事项**：“#”后面必须跟一个空格才能识别出来，否则标题会失效
```
# 正确用法
#错误用法
```
2. Markdown为每个标题创建了锚点，方便页内跳转  
[标题](#标题)
```
[显示的名称](标题)   /[]()要用英语输入法，标题格式记得带#，即#一级标题
```

```

### 单级引用的使用

> 这是一个引用块
> 这是一个引用块
> 这是一个引用块

### 多级引用嵌套

> 引用块

## 链接
- 基础语法
```
[链接名称](链接地址)
```
举个例子
> 这是我的[博客](https://moxlv.com "引号可以用作提示信息")
```

```
- 锚点链接
前面标题处介绍过，主要用于站内导航，非常适合作为长文章目录
[标题](#标题)
```
[标题](#标题)
```
- 双向链接
[One](/posts/blog/one/) 在obsidian中会失效网站有用
```
[One](/posts/blog/one/)  //[链接名称](绝对地址)
```
在obsidian中用下面两个
```
[One](./one.md)
[[one]]
```

## 数学公式
### LaTeX数学公式基础
在 Markdown 中，数学公式通过 LaTeX 语法来表示。LaTeX 是一个强大的排版系统，特别适用于包含复杂数学公式的文档。
#### 基本语法结构
- 命令：以反斜杠\开头，如\alpha,\sum
- 参数：用花括号{}包围，如\frac{a}{b}
- 下标:使用_，如x_1
- 上标：使用^,如x^2
- 分组：用花括号将多个字符组合，如x_{i+1}
#### 常用LaTeX命令
> ```
> \alpha, \beta, \gamma  % 希腊字母
\sum, \prod, \int      % 求和、乘积、积分
\frac{分子}{分母}      % 分数
\sqrt{表达式}          % 平方根
\sqrt[n]{表达式}       % n次根
> ```

### 行内公式和块级公式
#### 行内公式
使用单个$符号包围公式
如文本中的变量$x=5$和函数$f(x) = x^2 + 2x + 1$。
#### 块级公式
使用`$$`包围整个公式，公式会独立成行并居中显示
如
$$E = mc^2$$

$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$
> ```
> $$E = mc^2$$
> $$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$
> ```
#### 多行公式
使用align环境创造多行对齐公式
$$
    \begin{align}
    f(x) &= ax^2 + bx + c \\
    f'(x)  &= 2ax + b \\
    f''(x)  &= 2a
    \end{align}
    $$
```
$$
    \begin{align}
    f(x) &= ax^2 + bx + c \\  两个斜杠代表换行
    f'(x)  &= 2ax + b \\
    f''(x)  &= 2a
    \end{align}
    $$
```
